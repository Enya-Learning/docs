## Steps

<Steps>
  <Step title="Open Classrooms">
    From your student dashboard, open **Classrooms**.
  </Step>
  <Step title="Choose Join Classroom">
    Select **Join Classroom** to open the classroom code form.
  </Step>
  <Step title="Enter your class code">
    Type the code for your classroom, then select **Join Classroom**.
  </Step>
  <Step title="Check your classroom">
    After joining, return to **Classrooms** to find your class.
  </Step>
</Steps>

If the code is not accepted, check that it was entered correctly and confirm the code with your teacher.
