## Earn XP through course activities

These course activities each award **10 XP**:

- Complete a lesson
- Complete a video
- Complete a presentation
- Complete speech practice
- Complete an audio activity

Answering **5 questions correctly in a row** awards **5 XP**.

## Earn XP in games

Each game uses its configured reward rule. The number of correct answers required and the XP reward can vary, so check the in-app **How to earn XP?** panel for the current game rules.

## Check your XP

Open the XP summary on your student dashboard to review your XP totals and the current daily game XP limit.
